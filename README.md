# 20 Hillcrest Avenue garden model

- `model.html` is the working file (also published as the private Claude artifact).
- `index.html` is the public GitHub Pages copy. Rebuild it with `./build.sh` after any change to `model.html`.
- `tools/` holds the scripts used to read the plans, photos and video.
- Design options (pergola finish, hedge height, steppers, gate steps) are switchable in the Key panel. Picks are kept in the web address, e.g. `#pergola=charcoal&hedge=90`.
